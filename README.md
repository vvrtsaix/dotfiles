# dotFiles

Managed by [stow](https://www.gnu.org/software/stow).

## Getting Started

```shell
git clone git@github.com:vvrtsaix/dotfiles.git ~/dotfiles
```

## Modules

- `zshrc` / `zprofile` — zsh config
- `nvim` — neovim ([LazyVim](https://www.lazyvim.org/))
- `tmux` — tmux config (no plugins)
- `ghostty` — [Ghostty](https://ghostty.org/) terminal
- `yazi` — [yazi](https://github.com/sxyazi/yazi) file manager
- `scripts` — helper scripts in `~/.scripts`

## Requirements

- [neovim](https://github.com/neovim/neovim)
- [tmux](https://github.com/tmux/tmux)
- [ghostty](https://ghostty.org/)
- [yazi](https://github.com/sxyazi/yazi)
- [fzf](https://github.com/junegunn/fzf)
- [zoxide](https://github.com/ajeetdsouza/zoxide)
- [omz](https://ohmyz.sh/)
- [zsh-autosuggestions](https://github.com/zsh-users/zsh-autosuggestions/blob/master/INSTALL.md)
- [zsh-syntax-highlighting](https://github.com/zsh-users/zsh-syntax-highlighting/blob/master/INSTALL.md)
- [zsh-you-should-use](https://github.com/MichaelAquilina/zsh-you-should-use)

## Usage

```shell
cd ~/dotfiles
stow <module>
```
